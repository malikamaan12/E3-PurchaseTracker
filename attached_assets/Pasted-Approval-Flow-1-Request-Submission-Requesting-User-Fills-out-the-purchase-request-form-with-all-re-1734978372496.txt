Approval Flow
1. Request Submission
Requesting User:
Fills out the purchase request form with all required details.
Selects additional departments (e.g., IT, HR, Mall Management) for approval if needed.
Mandatory approvers:
CEO
Director
Finance
Submits the request.
2. Approval Workflow
Step 1: Notification:

Notifications are sent to all selected approvers through in-app notifications.
Step 2: Approval Process:

Approval Dashboard:
Approvers view the request details, including vendor information, payment terms, and milestones.
Options for approvers:
Approve: The request moves to the next approver (if applicable) or is finalized once Finance approves.
Reject: Sends the request back to the requester with comments.
Request Change/Modification: Approvers can suggest edits via a comment box (only allowed before Finance approves).
3. Rules for Modifications
Once any department and Finance have approved the request:
The request becomes locked for further modifications.
Requesting users can only view the status and progress.
Requests can only be modified by the requester before Finance approval or when changes are requested by an approver.
4. Role-Based Visibility
Requesting User:

Sees real-time status updates for their request.
Can view comments and requested changes but cannot edit after approval by Finance or any other department.
Approvers:

Each approver sees a dashboard of:
Pending Requests: Requests awaiting their action.
Approved Requests: Requests they’ve approved.
Rejected Requests: Requests they’ve rejected, with comments.
Admin:

Can:
Edit or delete any request.
View, track, and manage all submitted requests.
Override actions for emergency needs.
5. Comment Feature
Commenting Option:
Each approver can add comments during approval, rejection, or modification requests.
Comments are visible to the requesting user and subsequent approvers.
Comments are stored in the system for reference and audit purposes.
6. Approval Rules
Approval is no longer hierarchical.
Once a request is approved by Finance and at least one department, it is considered final and locked.
7. Notifications
In-App Notifications Only:
Submission notifications are sent to all selected approvers.
Approval/Rejection notifications are sent to the requester and other approvers.
Modification request notifications are sent to the requester with comments.
Approval Dashboard Layout
Requesting User Dashboard:
Features:
Request Status (Pending, Approved, Rejected, Locked).
Comments/Modification Requests.
Real-time progress tracker.
Request history and tracking ID.
Approver Dashboard:
Features:
Request Details.
Approval/Reject/Modify Buttons.
Comment Box for feedback.
History of actions and comments.
Admin Dashboard:
Features:
All requests with advanced filters (By Department, Requester, Status, etc.).
Edit/Delete Access for any request.
Comprehensive reporting and analytics.
