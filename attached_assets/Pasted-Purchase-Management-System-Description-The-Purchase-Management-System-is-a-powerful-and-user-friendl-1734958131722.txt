Purchase Management System Description
The Purchase Management System is a powerful and user-friendly application designed to streamline and simplify the purchase request and approval process across various departments within an organization. It ensures transparency, efficiency, and accountability while providing a centralized platform for managing purchase-related workflows.

Key Features and Capabilities
1. User-Friendly Request Creation
Any authorized user from departments such as Branding, Logistics, Mall Activation, etc., can create a purchase request through their respective login.
The request form captures essential details, including:
Items required.
Estimated costs and quantities.
Vendor information.
Purpose (e.g., event or project).
2. Seamless Approval Workflow
Notifications are sent to the approval departments as soon as a request is submitted.
Mandatory Approval Departments: CEO, Director, and Finance must approve each request.
Optional Approval Departments: Additional departments such as Mall Management, IT, or HR can be added as approvers by simply selecting them from the list.
Approvers can:
Approve or reject the request.
Request modifications for clarification or adjustments.
3. Document Management
Requests can be downloaded, printed, or modified at any time before approval begins.
Once a department has approved the request, further modifications by the requester are locked, ensuring process integrity.
4. Real-Time Progress Tracking
The requesting department can view the status of their requests in real time, including where they are in the approval process and any pending actions.
5. Administrative Control Panel
The Admin Panel provides comprehensive control to manage:
Users and roles.
Department configurations.
Approval workflows.
Vendor details.
System settings and notifications.
6. Enhanced Notification System
Notifications are sent at key stages:
Request submission.
Approval or rejection.
Queries or modification requests.
Option for WhatsApp notifications for quick updates and better accessibility.
Unique tracking numbers are assigned to each request for easy identification and follow-up.
7. Advanced Search and Filters
Powerful filtering options allow users to locate specific requests quickly, using criteria such as:
Request status (pending, approved, rejected).
Departments involved.
Event or project association.
8. Draft and Dashboard Features
Draft Mode: Users can save incomplete requests as drafts and complete them later.
Department Dashboards:
Each department has its own dashboard displaying relevant requests.
Provides insights into pending, approved, or rejected requests, ensuring clarity and accountability.
