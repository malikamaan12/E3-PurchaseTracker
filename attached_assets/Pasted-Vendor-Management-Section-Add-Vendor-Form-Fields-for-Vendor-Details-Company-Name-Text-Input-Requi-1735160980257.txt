Vendor Management Section
Add Vendor Form
Fields for Vendor Details:
Company Name (Text Input, Required)
Placeholder: "Enter the company name."
Contact Person (Text Input, Required)
Placeholder: "Enter the name of the contact person."
Contact Number (Text Input, Required)
Placeholder: "+Country Code XXXX-XXXXXX"
Validation: Accepts only numbers and "+" for country codes.
Email Address (Text Input, Optional)
Placeholder: "Enter email address."
Validation: Must follow proper email format.
Account Number (Text Input, Required)
Placeholder: "Enter account number."
IBAN Number (Text Input, Required)
Placeholder: "Enter IBAN number."
Validation: Must follow IBAN format (e.g., XX00 XXXX 0000 0000).
Bank Name (Text Input, Required)
Placeholder: "Enter the bank name."
Branch Name/Address (Text Input, Optional)
Placeholder: "Enter branch name or address."
Additional Details Section:
Vendor Address (Text Area, Optional)
Placeholder: "Enter the complete address of the vendor."
Vendor Category (Dropdown, Required):
Classify vendors by categories:
Materials Supplier
Service Provider
Logistic Partner
Equipment Rental
Others (with a text input for custom categories).
Payment Currency (Dropdown, Required):
Select payment currency:
USD
QAR
EUR
CNY
Rating Vendor (Star Rating or Dropdown, Optional):
Rate the vendor on a scale of 1-5 or Poor to Excellent.
Add optional comments for justification.
Vendor Status (Toggle Button):
Active: Default state.
Blocked/Freezed: Prevents vendor selection for new purchase requests.
Requires a reason for blocking/freezing, entered in a pop-up text field.
Admin Features:
Add Vendor Button
Opens the "Add Vendor" form in a pop-up or modal.
Vendor List View
Displays a table with columns for:
Company Name
Contact Person
Contact Number
Email
Address
Account Details (Account No., IBAN, Bank Name).
Vendor Status (Active/Blocked).
Rating (Stars or Numeric).
Search and Filter Vendors
Search by name, category, address, or rating.
Filter by vendor status (Active, Blocked).
Edit/Delete Vendor Information
Options available for admin users in the vendor table.
Freeze/Block Vendor Action
Accessible from the vendor table.
Pop-up for entering the reason before blocking/freezing a vendor.
Notification System:
In-App Notifications:
Notify relevant users when a vendor is blocked or reactivated.
Validation and Error Handling:
All required fields must be completed before saving.
Display inline error messages for invalid data (e.g., "Invalid email format" or ).
Prevent accidental deletion or blocking with confirmation dialogs.
